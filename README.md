# Sam Portfolio

An elegant portfolio and future business starter built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Personalise it

- Replace `public/images/hero-background.svg` with your own image (then update `app/page.tsx` if its file extension changes).
- Update your contact details and social URLs in `components/Footer.tsx`.
- Update title and introduction in `app/page.tsx`.

## Future business features

When you are ready for orders and payments, add a product database (Supabase/PostgreSQL), order API (FastAPI), and a payment provider such as Stripe or Razorpay. Never collect card information directly in this website.
